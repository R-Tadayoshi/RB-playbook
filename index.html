Riftbound Matchup Playbook

Pro lists by legend from the first Radiance weekend (Oct 23 to 25, 2026), shown card by card with each card's effect text, so you can read what you're playing against. Compiled Oct 29, 2026.

How to read this

Every list is a real top-8 list, not an average. Stats are RiftAtlas / TopDeck.gg for the last 30 days across all builds of that legend; a legend with under about 40 players has a small sample. Card text comes from the Riftcodex card database and RiftAtlas card pages. Where a Radiance card icon couldn't be read from the page it is written as shown on the card. Card images (when shown) load from RiftAtlas by card number; if one fails to load, the tile falls back to the text version. A card outlined in teal matches your search.
